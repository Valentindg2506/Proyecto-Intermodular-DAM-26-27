# SOFTWARE DE GESTION EMPRESARIAL - TINOPROP - CRM INMOBILIARIO

Problema: Una inmobiliaria utiliza WhatsApp, Excel, carpetas, Google Drive, portales inmobiliarios, calendario y diferentes herramientas para gestionar clientes y propiedades.

Solución: Crear un CRM que incluya todo eso en una misma plataforma.

-	Posibles modulos:

		-	CRM de compradores y vendedores.
		-	Propiedades y documentación.
		-	Buscador avanzado.
		-	Matching comprador ↔ propiedad.
		-	Gestión de visitas.
		-	Agenda.
		-	Seguimiento de operaciones.
		-	Documentos y contratos.
		-	Firma/documentación.
		-	Tareas.
		-	Comisiones.
		-	Portal del cliente.
		-	Panel de estadísticas.
		-	Comunicación con clientes.
		-	Usuarios y permisos.
		-	Automatizaciones.
		-	Aplicación móvil.
		-	API.
		-	Notificaciones.
	
-	El CRM tendría que responder a cinco preguntas:

		-	¿Quién es el cliente?
		-	¿Qué busca o qué quiere vender?
		-	¿Qué propiedades pueden encajar?
		-	¿En qué estado está la operación?
		-	¿Qué tiene que hacer el agente ahora?
